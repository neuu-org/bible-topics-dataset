# Bible Topics Dataset

5,745 biblical topics unified from two classic topical reference works (Nave + Torrey).

Part of the [NEUU](https://github.com/neuu-org) biblical scholarship ecosystem.

## Overview

| Metric | Value |

| Nave source topics (`data/02_sources/nave`, source-layer count) | 5,320 |

### Definition sources (not currently merged into `01_parsed`)

`data/03_pilot` topics carry definitions from Easton (EAS) and Smith (SMI),
sourced from [bible-dictionary-dataset](https://github.com/neuu-org/bible-dictionary-dataset)
and merged by an external enrichment pipeline. The published `01_parsed`
layer — the one measured in the Overview table above — does **not** carry
definitions: no script in `scripts/` reads bible-dictionary-dataset. See
[Roadmap](#roadmap) below.

All sources are **public domain**.

## Roadmap

Dictionary definitions and AI enrichment are the project's intended
direction for the full `01_parsed` layer, not something already shipped
there — today they exist only in the 336-topic `data/03_pilot` pilot. The
plan for extending both to the full dataset is written up in
[docs/ENRICHMENT_PLAN.md](docs/ENRICHMENT_PLAN.md), whose own status line
reads "PLANNED (not started)".

## Data Layers

### 00_raw — Original XML + Text

Original CCEL ThML XML files for Nave and Torrey. These are the authoritative sources before any parsing.

### 01_parsed — Merged V3

5,745 topics unified from Nave and Torrey. Each topic may contain:

| Field | Description | Coverage |
|-------|-------------|----------|
| `topic`, `slug`, `sources` | Identity | 100% |
| `biblical_references` | Biblical references | 100% |
| `definitions` | Dictionary definitions | 0% — not merged into this layer, see `data/03_pilot` |
| `definition_refs` | Refs extracted from definitions | 0% — see Roadmap |
| `ai_enrichment` | Summary, outline, key concepts | 0% — not run on this layer, see `data/03_pilot` |

### 02_sources — Separated by Source

Per-file topics from each source independently. Useful for provenance tracking and avoiding circularity in research.

- **nave/** — 5,320 topics with `canonical_id: NAV:*`, `biblical_references`, `see_also`
- **torrey/** — 622 topics with `canonical_id: TOR:*`, `biblical_references`, hierarchical structure

### 03_pilot — Fully Enriched Subset

336 topics (primarily letter A) with 100% AI enrichment and 85.7% (288) carrying dictionary definitions. Used as the official pilot for hybrid search research.

## Pipeline

```
00_raw/xml/nave_bible.xml   → parse_nave.py     → 02_sources/nave/    (5,320 topics)
00_raw/xml/torrey_ttt.xml   → parse_torrey.py   → 02_sources/torrey/  (622 topics)
                                    ↓
02_sources/ → clean_sources.py (normalize book names, in place) → 02_sources/
                                    ↓
02_sources/ → create_v3_unified.py → 01_parsed/ (5,745 merged)
                                    ↓
01_parsed/ → run_phase0.py (AI enrichment, external) → 03_pilot/ (336 fully enriched)
```

Dictionary-definition merging and definition-reference extraction are not
yet wired into this pipeline — see [Roadmap](#roadmap).

### Requirements

Python 3.10+ is required — the scripts use PEP 604 `X | None` syntax.

```bash
pip install -r requirements.txt
```

### Reproducing from scratch

```bash
# Step 1: Parse XMLs into per-source topics
python scripts/parse_nave.py --all --verbose
python scripts/parse_torrey.py --all --verbose

# Step 2: Normalize book names and extract inline references (in place)
python scripts/clean_sources.py --source all --verbose

# Step 3: Merge into unified V3
python scripts/create_v3_unified.py

# Step 4 (optional): Integrate cross-references (requires bible-crossrefs-dataset)
python scripts/integrate_crossrefs.py
```

Dictionary-definition merging is not part of this reproduction path today —
see [docs/ENRICHMENT_PLAN.md](docs/ENRICHMENT_PLAN.md) and the
[Roadmap](#roadmap) section above.
